# Frostbound — เกมหิมะสำหรับห้องเรียน

เกมเว็บภาษาไทยแนว Snowy Survival ที่บังคับตัวละครและตอบคำถามเพื่อรับทรัพยากร สร้างแผนที่และภาพขึ้นใหม่ ใช้กติกาหลักจากแนวเกมใน [วิดีโอตัวอย่าง](https://www.youtube.com/watch?v=R0ctUt-egro) และ [คู่มือ Gimkit](https://help.gimkit.com/en/article/snowy-survival-pplup6/) ไม่ได้ใช้บัญชีหรือระบบหลังบ้านของ Gimkit

เปิดเกมออนไลน์: https://frostbound-classroom.onrender.com

## เปิดเล่น

ต้องใช้ **Node.js 24 ขึ้นไป**

```powershell
cd "เส้นทางของโฟลเดอร์ frostbound"
pnpm install --frozen-lockfile
node server/index.js
```

หรือ `npm install` แทน `pnpm install` หากใช้ npm หลังจากติดตั้งแล้วเปิด `start.ps1` ได้

เข้า **http://localhost:3000** บนเครื่องที่เปิดเซิร์ฟเวอร์

## เริ่มเกมกับนักเรียน

1. ครูสมัครบัญชี เลือกบทบาท **คุณครู** แล้วกด **สร้างห้อง**
2. เลือกชุดคำถาม ระยะเวลา 1 / 3 / 5 / 10 นาที และความเร็วซอมบี้
3. นักเรียนใช้ QR ที่หน้ารอห้อง หรือรหัส 6 หลัก เข้าผ่านบัญชีหรือกรอกชื่อเล่น
4. รอผู้เล่นออนไลน์อย่างน้อย 2 คน ครูกดเริ่มเกม ครูจะเป็นผู้ดูแลสนาม
5. จบเกมแล้วดูอันดับ ดาวน์โหลดผล CSV หรือกดเล่นรอบใหม่ในห้องเดิม

ผู้เล่นที่เข้าสู่ระบบจะมีประวัติการเล่นในบัญชี ผู้เล่นแบบชื่อเล่นไม่ได้เก็บประวัติถาวร

หากอยากลองทันที กด **ทดลองผจญภัย** เพื่อเล่นกับบอท 3 ตัว โดยไม่ต้องสมัครบัญชี

## วิธีเล่น

| การกระทำ | คอมพิวเตอร์ | มือถือ |
| --- | --- | --- |
| เดิน | WASD หรือปุ่มลูกศร | จอยบังคับทิศทาง |
| เล็ง / ยิงบอลหิมะ | คลิกฉาก หรือ Space ตามทิศที่เดิน | แตะฉาก หรือปุ่ม ❄ ตามทิศที่เดิน |
| ตอบคำถาม | Q หรือปุ่มตอบคำถาม | ปุ่มตอบคำถาม |
| ปลูก / เก็บเกี่ยว / รักษา | E เมื่ออยู่ใกล้จุด | ปุ่มปลูก / เก็บเกี่ยว เมื่ออยู่ใกล้จุด |

- เกมสุ่มซอมบี้ 1 คนตอนเริ่ม คนที่เหลือต้องอยู่รอดจนหมดเวลา
- **คนตอบถูก:** พลังงาน +35 สูงสุด 100; **ซอมบี้ตอบถูก:** บอลหิมะ +8 สูงสุด 99
- ทุกคำตอบที่ถูกได้รับ 20 เหรียญ ตอบผิดแสดงเฉลยแล้วตอบข้อถัดไปได้
- คนเสียพลังงานเมื่อเดิน หากหมดจะเดินช้าลง ซอมบี้ไม่มีการใช้พลังงานเดิน
- ซอมบี้ยิงคนเสียพลังชีวิตครั้งละ 34 หน่วย โดน 3 ครั้งจะเปลี่ยนเป็นซอมบี้
- คนใช้เครื่องยิงยิงซอมบี้ให้หยุด 2.5 วินาที
- แปลงปลูกด้านล่างซ้าย: ใช้ 20 เหรียญ ปลูก 5 วินาที แล้วเก็บเครื่องยิงพร้อมบอลหิมะ 15 ลูก
- จุดพยาบาลด้านขวา: ใช้ 20 เหรียญ เพื่อฟื้นพลังชีวิต 50 หน่วย
- หากทุกคนติดซอมบี้ เกมจะจบก่อนหมดเวลา คะแนนเรียงจากเวลาที่รอดชีวิต ตามด้วยจำนวนคำตอบถูก
- สนามยังดำเนินต่อระหว่างตอบคำถาม ผู้เล่นจะหยุดเดินขณะเปิดหน้าคำถาม

## ชุดคำถาม

บัญชีครูเปิดเมนู **ชุดคำถาม** เพื่อสร้าง แก้ไข คัดลอก และลบชุดคำถามได้ รองรับ 1–100 ข้อ ข้อละ 4 ตัวเลือก เลือกคำตอบถูก 1 ข้อ มีชุด “รอบรู้รอบโลก” 10 ข้อให้เริ่มเล่นทันที

## QR Code และการเล่นคนละเครื่อง

ทุกอุปกรณ์ต้องเข้าถึง **เซิร์ฟเวอร์เดียวกัน** QR จะเลือก IP ของเครือข่ายในเครื่องโดยอัตโนมัติเมื่อครูเปิดผ่าน localhost

- เล่นใน Wi-Fi เดียวกัน: เปิดลิงก์ใต้ QR บนมือถือ หากเข้าไม่ได้ตรวจสอบว่า Windows Firewall อนุญาต Node.js และทุกอุปกรณ์อยู่ในเครือข่ายเดียวกัน
- บางเครือข่ายโรงเรียนแยกอุปกรณ์ออกจากกัน หรือเครื่องมีหลาย IP หาก QR เลือก IP ผิด ให้คัดลอก `.env.example` เป็น `.env` แล้วกำหนด `PUBLIC_URL=http://IP-ที่นักเรียนเข้าถึงได้:3000`
- กล้องสแกนในเว็บต้องใช้ **HTTPS หรือ localhost** ตามข้อกำหนดเบราว์เซอร์ เมื่อเปิดผ่าน IP แบบ HTTP ใช้ **เลือกรูป QR** หรือกรอกรหัสห้องแทนได้ กล้องปกติของมือถือใช้สแกน QR ที่หน้าครูเพื่อเปิดลิงก์ได้เช่นกัน
- เล่นผ่านอินเทอร์เน็ต: ต้องนำ Node.js app นี้ขึ้นเซิร์ฟเวอร์ที่รองรับ WebSocket ตั้ง HTTPS และ `PUBLIC_URL=https://โดเมนของคุณ` พร้อม `COOKIE_SECURE=true` เว็บออนไลน์เผยแพร่แล้วที่ https://frostbound-classroom.onrender.com

## ข้อมูลและขอบเขตเวอร์ชันนี้

ใช้ Node.js + Express + WebSocket + SQLite / PostgreSQL + Phaser 3 ตัวเกมและทรัพยากรคำนวณที่เซิร์ฟเวอร์

- บัญชี รหัสผ่านที่ผ่าน scrypt ชุดคำถาม และประวัติ เก็บใน `data/frostbound.sqlite` รักษาโฟลเดอร์ `data/` ไว้เพื่อไม่ให้ข้อมูลหาย
- เวอร์ชันออนไลน์ใช้ Supabase แยกเก็บบัญชี เซสชัน ข้อสอบ และประวัติ ส่วนการเปิดในเครื่องยังใช้ SQLite ได้
- ตั้ง `SUPABASE_URL` และ `SUPABASE_SECRET_KEY` เฉพาะฝั่งเซิร์ฟเวอร์ ถ้ามี `DATABASE_URL` ด้วย ระบบจะเลือก Supabase ก่อน
- เซสชันเก็บใน HttpOnly cookie อายุ 7 วัน มีการตรวจสิทธิ์ครู / ผู้เล่น จำกัดอัตราคำขอ และป้องกันตอบคำถามเดิมซ้ำเพื่อปั๊มรางวัล
- **ห้องและเกมที่กำลังเล่นอยู่เก็บในหน่วยความจำ** การปิดหรือรีสตาร์ตเซิร์ฟเวอร์จะทำให้ห้องเหล่านั้นหาย บัญชี ชุดคำถาม และประวัติที่บันทึกแล้วไม่หาย
- มีการเชื่อมต่อกลับอัตโนมัติระหว่างเซิร์ฟเวอร์ยังเปิดอยู่ หากเปิดบัญชีเดียวกันในห้องเดียวกันอีกหน้าจอ หน้าจอใหม่จะรับการเล่นต่อ
- ออกแบบจำนวนผู้เล่นต่อห้องสูงสุด 40 คน ทดสอบการเล่นพร้อมกัน 3 หน้าจอ ยังไม่ได้ทดสอบโหลดจริง 40 คน
- สมัครสมาชิกและล็อกอินในแอปได้ ยังไม่มีการยืนยันอีเมล ลืมรหัสผ่าน หรือเข้าสู่ระบบผ่าน Google
- มีระบบหลักของการเอาชีวิตรอด ตอบคำถาม ยิงหิมะ ปลูกเครื่องยิง และรักษา มีท่าตกปลาเพิ่มทรัพยากรแล้ว ส่วนภารกิจลับและไอเทมบางชนิดของเกมต้นฉบับยังไม่ได้จำลอง

## ตรวจสอบระบบ

```powershell
node --test tests/*.test.js
```

ทดสอบการชนสิ่งกีดขวาง การใช้พลังงาน การติดซอมบี้ การหยุดซอมบี้ การปลูกและเก็บเกี่ยว จบตามเวลา ป้องกันเปิดเผยคำตอบ สิทธิ์บัญชี ห้อง WebSocket รางวัล QR ประวัติ และเริ่มรอบใหม่

## เผยแพร่บน Render

มี `render.yaml` สำหรับ Node.js 24 บน Render ภูมิภาคสิงคโปร์ ตัวเกมเลือก URL HTTPS จาก `RENDER_EXTERNAL_URL` อัตโนมัติ มี `/healthz` ตรวจทั้งเว็บและฐานข้อมูล และคุกกี้ Secure เปิดอยู่ในค่าการเผยแพร่

Render แบบฟรีจะพักเว็บหลังไม่มีทราฟฟิก 15 นาที การเปิดครั้งแรกหลังพักอาจต้องรอประมาณ 1 นาที ตาม [ข้อจำกัดแพ็กเกจฟรีของ Render](https://render.com/docs/free)

บัญชีและข้อสอบเก็บบน Supabase ซึ่งแยกจากตัวเกม ใช้แพ็กเกจฟรีตามโควตา Supabase แพ็กเกจฟรีอาจพักโปรเจกต์หลังไม่ได้ใช้งาน 1 สัปดาห์ ตาม [เงื่อนไขของ Supabase](https://supabase.com/pricing) ควรสำรองข้อมูลสำหรับการใช้งานห้องเรียนระยะยาว

ก่อนเริ่มใช้งาน ให้ใช้ `server/supabase-schema.sql` สร้างตาราง `frostbound_users`, `frostbound_sessions`, `frostbound_quizzes`, `frostbound_matches` เปิด RLS และอนุญาตเฉพาะ backend ผ่าน server secret key ผู้เล่นเรียก API ของเกมซึ่งตรวจบัญชีและสิทธิ์แล้ว ไม่ได้อ่านรหัสผ่านหรือเฉลยผ่าน Supabase โดยตรง

เก็บ `SUPABASE_SECRET_KEY` ใน Environment ของ Render เท่านั้น ห้ามใส่คีย์ลับ รหัสผ่านฐานข้อมูล หรือไฟล์ `.env` ลง GitHub คีย์ไม่ถูกส่งไปในหน้าเว็บ

## เวอร์ชันปรับเกม 14 ตุลาคม 2026

ใช้ตัวละครการ์ตูนต้นฉบับ 6 แบบพร้อมซอมบี้ ภาพเมืองหิมะใหม่ รั้ว ทางเดิน บ้าน ตุ๊กตาหิมะ ท่าตกปลา และแผนที่ย่อ (M) การเล็งแยกจากทิศเดิน กดค้างเพื่อยิง มีเสียงและเอฟเฟกต์การยิง/โดนหิมะ เปิดหรือปิดเสียงได้

เริ่มเกมมีช่วงเตรียมตัว 6 วินาที โหมดฝึกมีบอท 5 คน ผู้เล่นเริ่มพร้อมเครื่องยิงและหิมะ 15 ลูก โหมดฝึกหยุดสนามและเวลาเมื่อเปิดคำถามหรือคู่มือ ส่วนห้องเล่นร่วมกันยังเล่นต่อระหว่างตอบ คำถามเลือกด้วยปุ่ม 1–4 ได้

ท่าตกปลา: เดินไปท่า กด E รอ 3 วินาทีแล้วกดเก็บ รับหิมะ 10 ลูก พลังงาน 15 และเหรียญ 10 ลูกหิมะตรวจการชนตลอดเส้นทาง รั้วและฉากกันหิมะได้ มือถือลากจอยและกดปุ่มยิงค้างได้
